# Contributing

Please write repository content, issues, and pull requests in English. Start with an issue for a substantial change, or submit a focused pull request for a correction or example.

Describe the problem, proposed change, evidence, and limits. For experience reports, include the workflow, relevant tool/version context, acceptance criteria, failures, supervision time, and measurement period. Mark proposals as proposals; do not claim testing that did not happen.

Keep changes small and practical. Check Markdown links, remove personal/client data and credentials, and preserve source attribution. Do not upload third-party documents without permission. Examples should use fictional or properly anonymized data.

By submitting a contribution, you agree to make your original contribution available under this repository's MIT License. Include attribution and compatible permissions for any third-party material.

Challenge ideas respectfully. Avoid personal attacks, promotional spam, and unsupported guarantees. Never post sensitive incident details in a public issue.
