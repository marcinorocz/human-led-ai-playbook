# A decision without pressure

Use only when a human decision is genuinely required (One-Way Door / Irreversible commitment). Keep it short (BLUF); show supporting detail on request.

**Decision:** One sentence stating the core choice.

**Type & Reversibility:** 
- [ ] One-way door (Irreversible / High-consequence: requires human consent)
- [ ] Two-way door (Reversible: recommendation already applied or proposed, human input optional)

**Why now:** Actual deadline and consequence, or “This can wait.”

**Proposed change and scope:** What will change, who or what is affected, and exactly what approval permits.

**Quality at Source (TQM Pre-flight):** Automated tests, linter, or sanity checks executed prior to this request. Never ask the person to catch mechanical defects.

**What we know:** Key evidence, material uncertainty, and what has not been checked. Link supporting detail where available.

**Recovery:** Can this be reversed, by whom, and with what known limits or cost? State when unknown.

**Review effort:** Estimated time to understand and check the proposal, including follow-up; an estimate, not a quota. If it exceeds agreed capacity, recommend reducing scope or deferring.

| Option | Outcome | Human effort and trade-off |
| --- | --- | --- |
| A — Recommended | | |
| B — Alternative | | |
| C — Pause, reduce, or decline | | |

These options are aids, not a restriction on the person's choices.

**While waiting:** No new consent is assumed. Hold gated actions and respect protected time. Do not repeat nonurgent reminders. If the agreed approval capacity is full, consolidate related requests and slow or pause additional demand-generating work within authority. Disclose what cannot be controlled; keep real external deadlines visible.

**Decision, if made:** Record the choice and its scope. Do not record health information or a private explanation for declining.

If the person has already said stop, acknowledge the stop instead of asking them to fill in this card.
